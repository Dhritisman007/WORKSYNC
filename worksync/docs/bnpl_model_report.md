# Credit card / BNPL vertical — model report

Generated by `worksync/verticals/bnpl/model/train.py` against the
Kaggle Credit Card Fraud Detection dataset (`mlg-ulb/creditcardfraud`).
Numbers below are from an actual run, not estimated.

- Dataset: 284807 transactions, positive (fraud) rate 0.00173
  (this dataset is heavily imbalanced — 492 frauds out of 284,807 rows).
- Split: stratified 227845 train / 56962 test (80/20), seed 42.
- Primary model: LightGBM, isotonic-calibrated (prefit on a held-out
  slice of the training split). XGBoost is a comparison baseline only.
- Features: `amount`, `hour_of_day` (derived from `Time`), and the
  dataset's 28 PCA-anonymized components (`v1`..`v28`) passed through
  unchanged — they have no recoverable human-readable meaning, which
  is also why `rules.yaml` for this vertical only covers `amount`.

## Notes

- No customer/session identifier exists in this dataset, so no
  velocity-style feature (unlike the KYC/AML vertical) was added —
  it isn't supportable by the data, so it wasn't fabricated.
- 0.5 is a reporting threshold for this table only; the Manager
  Agent's real bands come from `verticals/bnpl/manager_config.yaml`.
